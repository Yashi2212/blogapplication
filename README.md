# Blog Application

Live demo: https://yashi2212.github.io/blogapplication/

A React and Redux blog with create, read, edit, delete and like actions. The GitHub Pages demo stores changes in this browser only using localStorage; changes are not shared with other visitors. Sample posts are bundled in `my-static-api/db.json`. No external API is required.

Run `npm ci`, then `npm start`. Run `npm run build` for a production build. GitHub Actions builds and deploys the site when `main` changes. Hash routing supports direct links and refreshes on Pages.

Missing source files were recovered from this project's existing production source maps before publication.
